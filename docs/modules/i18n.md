# Language (i18n)
- Dictionaries: `src/locales/en.ts`, `src/locales/id.ts` (flat key -> text). Module/group names: English = official registry (`src/lib/modules.ts`, never edited by i18n); Indonesian display names = `src/locales/names.ts` (editable, needs owner approval).
- Use: `const { t, modName, groupName } = useI18n();` then `t("key")`. Missing keys fall back to English, then to the key itself.
- Language switch: Topbar and login page; saved in localStorage; default follows the browser (Indonesian browsers -> id).
- Phase 1 translated: sidebar, launcher, topbar, search, login/guest box, dashboard, module page chrome, status labels, cross-module action buttons.
- Not yet translated: page-specific labels, helper notes and error messages in most module pages (mixed Indonesian/English today). Add keys per page as they are converted.
